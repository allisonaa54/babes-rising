# Babes Rising

See the pattern. Trust yourself. Know your worth. Rise.

Expo mobile app for educational relationship-awareness assessments, private reflection, dating tracking, and cautious dating-profile analysis.

## Build configuration

The app requires these Expo public environment variables during builds:

- `EXPO_PUBLIC_DOMAIN`
- `EXPO_PUBLIC_REVENUECAT_TEST_API_KEY`
- `EXPO_PUBLIC_REVENUECAT_IOS_API_KEY`
- `EXPO_PUBLIC_REVENUECAT_ANDROID_API_KEY`

Do not commit their values to this repository. Configure them in Expo/EAS.
